**代码层面的开源项目**

| 序号 | 名称与版本 | 来源 | 许可协议 | 用途 | 是否修改 |

**工具链与第三方工具**

| 类别 | 工具与版本 | 用途 |
|---|---|---|
| 编译器 | `arm-none-eabi-gcc` 16.1.0 | 编译固件 |
| 构建 | CMake + Ninja | 配置与增量编译 |
| 环境 | MSYS2 UCRT64 | 提供工具链运行环境 |
| 下载调试 | OpenOCD + ST-LINK | 烧录、变量监视、时序探测 |
| 建模 | Fusion 360（教育 / 个人版） | 底盘、单臂、托架设计与出图；源文件不随仓库分发 |
| 打印 | 校内外 3D 打印服务 | PLA 结构件打印 |

引脚与定时器初始化代码最初由 STM32CubeMX 生成（`lesson2.ioc` 保留），生成后编译链路改为上述开源工具链，日常不再打开 CubeIDE。队伍逻辑写在 `USER CODE` 区域与独立的 `.c` / `.h` 文件中，重新生成代码不会覆盖。CubeMX 只承担初始化代码生成，不参与日常构建；这一边界保证了工具链可替换，也避免生成代码覆盖手写逻辑。

**合规性说明**

| 手册规定 | 本项目情况 |
|---|---|
| 严禁直接购买功能成熟的商品机器人或机器人套件；成品 PCB、电压管理等成品模块、视觉套件不在此范围 | 底盘框架、单臂、托架均为自行设计并 3D 打印；仅采购 DRV8833、MG995 / SG90、稳压模块等标准件 |
| 机器人与遥控器之间的通信方式仅可选一种，收发源有且仅有一组 | 仅使用 PS2 手柄 2.4G 一种无线方式，一套接收器 |
| 视觉模块（规划中） | 与主控之间为板载有线串口，不属于"机器人与遥控器之间"的无线通信；不使用无线模块对外通信 |
