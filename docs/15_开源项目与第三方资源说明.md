# 开源项目与第三方资源说明

> 手册要求：将开源项目用于机器人制作及代码编写的，必须在中期考核阶段给出完整说明，并遵守所使用开源项目的开源协议。

## 一、 代码层面使用的开源项目

| 序号 | 名称与版本 | 来源 | 许可协议 | 用在哪里 | 是否修改 |
|---|---|---|---|---|---|
| 1 | STM32F1xx HAL Driver **V1.1.10** | STMicroelectronics 官方 STM32CubeF1 软件包，位于 `Drivers/STM32F1xx_HAL_Driver/` | BSD-3-Clause | GPIO / TIM 初始化、四路电机 PWM 输出、时钟配置、中断优先级 | 未修改任何源文件，只调用标准 API |
| 2 | ARM CMSIS + ST 器件头（`stm32f1xx.h`、`stm32f103xb.h`、`system_stm32f1xx.h`、启动文件） | ARM / ST 官方仓库，位于 `Drivers/CMSIS/` | Apache-2.0 | 寄存器定义、启动流程、系统时钟 | 未修改内容；因原工程缺失器件头文件，于 10-11 从 ST 官方仓库**补齐** |
| 3 | 塔克创新 PS2 无线手柄资料包 | 手柄采购时随附的资料包 | 资料包内未标注开源许可，**仅作技术参考** | 参考其软件 SPI 的时序与命令格式 | 参考思路，代码自行重写；修正了参考实现的采样沿问题、加了模拟模式恢复与数字模式保护 |

**说明**：第 3 项没有标注明确许可协议，因此我们的做法是**只参考时序与协议格式，不复制代码**，最终 `ps2.c` 为自行重写。

## 四、 工具链与第三方工具

这些不是随仓库分发的代码，但属于研发过程中的第三方资源，一并写清楚。

| 类别 | 工具与版本 | 用途 |
|---|---|---|
| 编译器 | `arm-none-eabi-gcc` **16.1.0** | 编译固件 |
| 构建 | CMake + Ninja | 配置与增量编译 |
| 环境 | MSYS2 UCRT64 | 提供上述工具链的运行环境 |
| 下载调试 | OpenOCD + ST-LINK | 烧录、变量监视、时序探测脚本 |
| 建模 | Fusion 360（教育/个人版） | 底盘、单臂、托架的三维设计与出图，**源文件不随仓库分发** |
| 打印 | 校内外 3D 打印服务 | PLA 打印结构件 |

> 说明：引脚与定时器的初始化代码最初由 STM32CubeMX 生成（`lesson2.ioc` 保留），生成之后**编译链路改为开源工具链**。自己的逻辑全部写在 `USER CODE` 区域和独立的 `.c/.h` 文件中，重新生成代码不会覆盖。

## 五、 AI 辅助工具使用说明

在本次备赛过程中，队伍合理使用了 AI 工具辅助开发，具体说明如下：

- **使用的工具**：DeepSeek Harness。
- **具体用途**：主要用于 **PS2 无线手柄通信代码** 和 **机械臂舵机控制代码** 的辅助开发、代码结构讨论及底层逻辑梳理。
- **队伍把控与责任**：AI 生成的所有代码片段、建议方案，均由电控成员经过**逐行走读、逻辑验证与实车测试**后才合入工程。AI 仅作为效率工具，队伍对整机的最终代码质量、硬件安全及实车表现负全责。

## 六、 合规性声明

| 手册规定 | 我们的情况 |
|---|---|
| 严禁直接购买功能成熟的商品机器人或机器人套件参赛；成品 PCB、电压管理等成品模块、视觉套件不在此范围 | 底盘框架、单臂、托架均为自行设计并 3D 打印；仅采购了驱动模块（DRV8833）、舵机（MG995/SG90）、稳压模块等标准件 |
