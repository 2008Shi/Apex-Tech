**验证与留证方式**

采用手机固定机位，每项指标单独录制一段视频，文件名对应指标编号；尺寸、质量与跌落高度在画面内以直尺标示。"底盘运动（全部）"的"全部"指全部车体水平运动，最终视频包含前进后退、横移与原地旋转，并与 PS2 手柄同框，便于评委确认是遥控而非预编程。

**当前状态**

截至 2026-10-18，中期考核 12 项基础指标均已完成并留取视频。整机初始尺寸 245 × 185 × 198 mm，质量 1.52 kg；180 mm 跌落测试在结构加固后通过，并复测三次。视觉模块处于方案论证阶段，未产出可展示的识别结果，不在指标表中报"已完成"。
