## 画圆模式与摇杆手感标定

**功能描述：** 在四轮解算基础上改善低速操控手感，并提供一种无需外部定位的定半径画圆运动模式。手感标定解决"轻推不走、稍推即窜"的问题；画圆模式使车体在固定横移速度与旋转角速度下绕圆心运动，半径由两个分量的比值决定。

**开发历程：** 早期 PWM 为 100 档时，摇杆轻推一大段车辆不动，再推一点点便突然窜出，无法微调。原因是电机启动门槛约为 25 — 35% 占空比，100 档下门槛附近的可用档位太少。10 月 13 日采取以下四项措施：

| 措施 | 参数 | 效果 |
|---|---|---|
| PWM 提档 | PSC 71 → 8，ARR 99 → 799，载波仍为 10 kHz | 档位由 100 提至 800；电机启动门槛附近可用档位增加 8 倍，低速可用下限由 462 降至 58 |
| 起步占空比 | `DRV_MIN_DUTY = 280`（35%） | 非零指令从此值起步，兼顾"轻推能走"与"最慢可控" |
| 摇杆曲线 | `out = 0.4x + 0.6x³`（`STICK_LINEAR_PCT = 400`） | 轻推 10% 仅输出 4% 速度，推到底仍为 100%；只缩放三个分量，不改变摇杆方向 |
| 四轮微调 | `WHEEL_TRIM_*`，一次只调一轮，每次不超过 30 点 | 用于修正直线偏差；trim 差异超过 ±10% 会使画圆变形为椭圆 |

摇杆曲线采用三次项而不是简单线性缩放，原因是轻推段需要更细的分辨率，而推到底仍要保留满速。曲线只作用于分量大小，不改变方向；因此前进、横移与旋转的合成方向保持不变，操作手不需要重新适应方向映射。

画圆模式最初采用心形轨迹表，需要 435 个点、生成脚本与归一化处理。心形尖点与凹口处的切向速度精确为 0，每圈有两次车几乎停下；此外查表需要处理 dt 补偿，主循环被拖慢时轨迹会变形。后来改为解析解：只要车头始终朝向圆心，车辆只做横移，横移速度等于角速度与半径之积，车身转角等于绕过的弧角；代入麦轮的两个线性关系后，车速在推导中约去，得到

```
R = L · vy / (2ω)
```

因此每帧只需给出三个常数（`vx = 0`、`vy`、`omega`），无需查表与 dt 补偿，主循环偶有延迟只会使旋转变慢，圆的形状不变。默认参数为 `CIRCLE_PEAK = 750`、`CIRCLE_OM_PCT = 364`，对应直径约 0.40 m。心形轨迹相关的 `heart.c`、`heart_table.c` 与生成脚本已于当日删除，避免保留两套互相矛盾的轨迹实现。

**验证与遗留：** 四项手感措施完成后，低速段可以一格一格加速，轻推不再突然窜出；四轮 trim 需在实车上逐轮标定，trim 差异超过 ±10% 时画圆会被拉成椭圆。画圆代码目前因圆圈键改为机械臂小臂右转而暂不触发，推导与常数保留在 `circle.h` 中，可在需要时恢复；恢复前需要重新确认键位与底盘旋转的复用关系。底盘仍为开环控制，没有编码器反馈，画圆形状受电池电压、地面摩擦与四轮差异影响，正赛前应结合 trim 复测。
